# Shared skills

Skills committed here are shared by all four developers, so everyone's agent
behaves the same way regardless of which IDE they use.

```
.claude/skills/<skill-name>/SKILL.md
```

Cursor and Antigravity users: point your tool at this folder, or symlink it,
so there is one copy rather than four drifting ones.

Rules:
- A skill lands here through a pull request like any other change.
- If a skill changes how the team works, note it in `brain/08-decisions.md`.
- Do not keep personal skills here — this folder is shared.
