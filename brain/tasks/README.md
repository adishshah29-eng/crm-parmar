# Task backlogs

One file per developer, with the ticket-level work for Weeks 1–4.

| File | Owner |
|---|---|
| `adish-tasks.md` | Foundation, shared core, super_admin and admin console, dashboards |
| `arisha-tasks.md` | Manager and sub_manager portal |
| `tanishka-tasks.md` | Caller portal |
| `sayli-tasks.md` | Attendance, geofences, site visits |

These are the *what*. The *when* is `brain/IMPLEMENTATION-PLAN.md`.
Phase 0, which blocks everything, is `brain/PHASE-0-RUNBOOK.md`.

Read your own file fully before Week 1 starts. If a task is unclear, ask in
your `brain/team/<name>.md` rather than guessing — a wrong assumption here
costs days, not hours.

Before your first ticket, read `brain/workflow/team-playbook.md`: how to set up, the loop for every task, and what to do first.
